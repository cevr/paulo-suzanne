# Restaurant Website Publishing

This context describes how restaurant information moves from private editorial work to the public website.

## Language

**Site content**:
The complete bilingual information and media references rendered on the public restaurant website.
_Avoid_: CMS data, payload

**Draft**:
A private revision of Site content that an editor can save and resume without changing the public website.
_Avoid_: Unpublished content, working copy

**Publish**:
The act of replacing public Site content with the current Draft and starting the website deployment that makes it visible.
_Avoid_: Save, deploy

**Asset**:
An image or menu document selected by an editor for use in Site content.
_Avoid_: File, upload
